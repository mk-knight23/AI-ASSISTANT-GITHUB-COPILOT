Critical Setup Tip Most People Miss

Go to VS Code Settings → Search "Copilot Reasoning" → Change to HIGH. This makes a dramatic difference in output quality. Responses take longer but the improvement is significant. Don't use Copilot without this enabled.

Agent Mode

Skills (/commands)

/tests, /explain, /fix, /review, /docs — invoke reusable workflows with slash commands. Create custom skills from extensions.

Lifecycle Hooks

Automate at key events — lint before apply, block protected files, auto-commit on exit, run tests on logic changes.

Agent Memory

Persistent context across sessions — coding agents, CLI, code review. Remembers conventions and architectural decisions.

Integrated Browser

Validate UI changes without leaving VS Code. Agent implements, loads browser, inspects result, adjusts code — one loop.

Session Forking

/fork creates parallel sessions with full history. Explore "minimal design" vs "feature-rich" without losing context.

Terminal integration with VS Code sync. Right-click code → send to CLI. Suggest, explain, run — all from terminal.
